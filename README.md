# 中食 実績分析ツール

日々の中食(米飯・調理麺・調理パン・サラダ・総菜・デザート・パン)の販売数・廃棄数を入力し、
重回帰分析と発注提案に活用するための Web アプリです。

## 主な機能

- **入力**: 日付・気温・天気・特売/催事の有無とあわせて、カテゴリ別の販売数・廃棄数を記録します。廃棄率は自動計算されます。
- **一覧**: 登録済みの実績をカテゴリ別・合計で一覧表示し、編集・削除ができます。
- **分析**: 曜日・気温・天気・特売の有無を説明変数とした重回帰分析を実行し、決定係数(R²)や係数、有意性の目安を確認できます。
- **発注提案**: 分析結果(データが十分な場合は重回帰モデル、不足時は同一曜日の平均実績)をもとに、指定した目標廃棄率になるようカテゴリ別の推奨発注数を算出します。

データはブラウザの localStorage に保存されます(サーバーには送信されません)。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番用ビルドを作成できます。
