# 中食 実績分析ツール

日々の中食(米飯・調理麺・調理パン・サラダ・総菜・デザート・パン)の売上金額・廃棄金額を入力し、
重回帰分析と発注提案に活用するための Web アプリです。

## 主な機能

- **入力**: 日付・最低/最高気温・天気・セール対象カテゴリ・祝日とあわせて、カテゴリ別の売上金額・廃棄金額(円)を記録します。廃棄率は自動計算されます。気温・天気は地点を設定しておけば[Open-Meteo](https://open-meteo.com/)から、祝日は[holidays-jp](https://github.com/holidays-jp/api)から自動取得できます(いずれもAPIキー不要)。毎回の入力に必須ではない天候・セール・祝日欄は折りたたみ式にしてあります。ナビゲーションは画面下部のアイコンから切り替えます。
- **インポート**: 日付・カテゴリ別の列を持つExcel(.xlsx / .xlsm)を読み込んで、既存の実績データを一括で取り込めます。売上シートと廃棄シートが分かれている場合は、複数シートを選択すると日付単位で自動統合されます。
- **一覧**: 登録済みの実績をカテゴリ別・合計で一覧表示し、編集・削除ができます。
- **分析**: 曜日・気温・天気・セール・祝日を説明変数とした重回帰分析を実行し、決定係数(R²)や係数、有意性の目安を確認できます。
- **発注提案**: 分析結果(データが十分な場合は重回帰モデル、不足時は同一曜日の平均実績)をもとに、指定した目標廃棄率になるようカテゴリ別の推奨発注金額を算出します。

データはブラウザの localStorage に保存されます(サーバーには送信されません)。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番用ビルドを作成できます。

## CI/CD

- `.github/workflows/ci.yml`: `main` への push / PR で型チェック・lint・ビルドを自動実行します。
- `.github/workflows/deploy.yml`: `main` に push されるたびに GitHub Pages へ自動デプロイします。

デプロイを有効にするには、リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください(初回のみ)。

今後の開発フロー: 変更用ブランチを作成 → PR を `main` に対して作成(CI が自動実行) → マージ → `main` への push をトリガーに自動デプロイ、という流れを想定しています。
